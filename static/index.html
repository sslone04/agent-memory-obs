Terminology
raw
candidate memories the vector search found
returned
how many survived the cutoff and reached the agent
floored out
raw > 0 but returned = 0: found, then discarded
top sim
best match score, 0 to 1, before the cutoff applies
floor / cutoff
the minimum score a result must reach to be returned
near miss
scored just under the floor: probably should have been returned
genuine miss
scored far below the floor: correctly rejected
blind
an agent answer produced with zero memories retrieved
effective age
how old the FACT is, as opposed to when the row was written
eviction
memory removed on expiry, not deleted by a user
